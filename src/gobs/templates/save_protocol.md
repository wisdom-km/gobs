## Save via gobs

When the human asks to save to the vault (`写进库`, `记下来`, `save to vault`,
or `/save-to-vault`), follow the **save-to-vault** skill. Run `gobs save`.
Do **not** paste the chat into a current note.

- Distilled note = conclusions, decisions, follow-ups.
- Optional raw chat = `gobs save --chat-file …` into the transcripts folder.
- Mark citations as `[pN]` in the distilled note so they become wikilinks to
  that paragraph (`#^gobs-YYYYMMDD-N`).
