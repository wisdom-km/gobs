2. **库图静帧**：matplotlib / graphviz 的 PNG 仍可用于左右对照。当场跑

   或 `python 80_meta/gobs-viz/draw.py coref --out PATH.png`
   图跟讲解同一轮出现，链回领域卡。
3. **讲解里的 Mermaid**：当场画「怎么走 / 谁连谁」，跟讲一起出现，不要只在课后补。
4. **ASCII 兜底**：这轮库图还没好，先用 ASCII 把过程画出来，不要空讲。
5. **可选**：[[draw.html]] 还在（看谁 / 印象包 / 地图）。适合点词、画「看谁」。能用就用，不是过程课主路径。
