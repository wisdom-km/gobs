# 画图

**双编码**：过程必须能看见。图给成年人：先准，再通俗。不是绘本，不是幼儿园插画。

**禁止**用图像生成模型出图。

跟 AI 上课本来就要联网。调用库才是正路，不限离线 HTML。

优先顺序：

1. **课桌（主路径）**：`gobs learn desk`。对话、图、笔记同一页。图的内容写在 `80_meta/gobs-viz/figure.json`：按**这篇**论文的例子，不要套死小猫句。教课锁论文标，对方只揭开；测验课（retrieve / feynman）自己标再 `gobs learn judge` / 交卷。
2. **动态图（无课桌时）**：用户可操作的步进图（[[process.html]]）。上一步 / 下一步，点词跳步。**不是**自动播的 gif。刚学按论文替对方标高低（默认句：it → animal 高、street 低、tired 中），不要让对方把每个词都点成高。过程随时间展开时，打开 `80_meta/gobs-viz/process.html`，让对方自己点下一步揭开。
3. **库图静帧**：matplotlib / graphviz 的 PNG 仍可用于左右对照。当场跑
   `python 80_meta/gobs-viz/draw.py seq-vs-attn --out PATH.png`
   或 `python 80_meta/gobs-viz/draw.py coref --out PATH.png`
   图跟讲解同一轮出现，链回领域卡。
4. **讲解里的 Mermaid**：当场画「怎么走 / 谁连谁」，跟讲一起出现，不要只在课后补。
5. **ASCII 兜底**：这轮库图还没好，先用 ASCII 把过程画出来，不要空讲。
6. **可选**：[[draw.html]] 还在（看谁 / 印象包 / 地图）。适合点词、画「看谁」。能用就用，不是过程课主路径。
   GIF 导出（`python 80_meta/gobs-viz/draw.py process --out PATH.gif`）只是可选导出，不是课堂上那张图。

encode 课画当前那 1 个组块。map 课画当前节点（拆/留必须左右对照出现在同一张）。一次一张。
