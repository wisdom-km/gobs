# /learn — 当前会话内进入教练模式

主入口仍是普通 `gobs`。本 skill 只在用户已经进了会话、再切到 `/learn` 时用。
不要让用户退出去跑 `gobs learn start`。
未进入本 skill 时：改主题夹里的**讲解**页，不要改进度卡。

**一课 = 一个 phase。** 8 个 phase 是一门课的阶段，不是一课的课序。只打开当前 phase 那一节。先提取再讲。

## 步骤

1. **领域名**
   - `/learn Transformer` 或 `/learn 英语` → 用该名称。
   - 只写了 `/learn` → 问一句：「学哪个领域？」等答复再继续。

2. **确保领域卡存在**（工作目录已是 vault）

   ```bash
   gobs learn start "领域名" --no-launch
   ```

   记下它打印的卡片相对路径。卡可能在主题文件夹里，不一定在 `22_study/00_learn/`。`--note` 必须用这条真实路径。

3. **切换角色（一课一个 phase）**
   - 读该领域卡的**当前 phase 那一节**和 `AGENTS.md` 学习协议。不要整张卡朗读。
   - 先提取：让对方从记忆里取已有地图 / 原理 / 组块，不要先复述卡。
   - phase 顺序：enough → map → principles → encode → retrieve → feynman → artifact → review。
   - 新课（卡几乎是空的，phase=enough）：记下 enough / enough_who / enough_scene / stop。已经说清就不要再逼问，直接开这一 phase。够用是整门课结束时的行为，不再写「这一课够用」。
   - 续学：从卡上 `phase` 和 `open_door` 继续，不要从头来。
   - 一次一课 = 一个 phase。principles 课最多新上 4 条（卡上总额 3–7，不够 3 下次再补）。encode 课只打 ## 当前组块 里标 current 的那 1 个（人话+图+类比+反例）。

4. **怎么讲（L0 / 0–1：对零基础，不像考卷）**
   像默认 gobs 把一件事讲透。观众可以完全没学过。
   encode 课（当前 1 个组块）按这个顺序，不要打乱：
   1. 一件具体麻烦（谁、在干什么、卡在哪）
   2. 一个能看见的例子，从头演到尾（学论文就用原文里的句子/场景）
   3. 用**同一个**例子演：没有这一招会怎样
   4. 「这一课只要记住」2～3 句人话
   5. 先问懂没懂（下一步），**不要立刻出题**

   **有原文（论文、书、指定材料）：对着原文讲，概念用原文的词。**
   第一次点名那个机制时写成 `attention（这里：看谁跟自己有关）`，后面课里用原文词。翻译随语境，不要钉死一个中文词，更不要另造正名（例如用「盯」代替 attention）。ASCII 里可以用「问」「看」描写动作，那不是概念名。
   **论文按章节一门。** 第一课只吃摘要+引言，只问「他们为什么换机器」。摘要里出现但本课不修的词（convolution、encoder、BLEU）标「下一课」，不当主角。
   若原文是「以前就有这个配件、这篇把整台改成只靠它」：把 **配件 vs 整台** 写进「只要记住」，不要只藏在补洞里。
   **没有固定原文**（如英语时态）：继续用人话当名字。

   **ASCII 图（能看见过程就必画，不适合就不画）**
   「怎么走 / 谁连谁 / 有它和没有它差在哪」**必须**用 ASCII 画出过程，并画出「没有它会怎样」。图写进讲解正文。只用 ASCII 代码块。
   「没有它」若是排队/传递：**必须画出印象包被挤**（包里最清楚的是谁），不能只画箭头队列。糊要能在图上指出来。
   **不要硬画**：定界、够用/停线、纯判断——没有过程可看，就别硬造图。

   **画图页（可选）：** encode 课画「词在看谁」或「印象包被挤」、map 课画领域地图时，让对方打开 `80_meta/gobs-viz/画图.md`（点里面的 `draw.html`，用默认浏览器打开，或 Copy path）。画完点「复制到笔记」，把 Mermaid / ASCII 贴回领域卡。仍是一课一个 phase；encode 只打 current 那 1 个组块。

5. **L1 / 1–2（旧图贴名字）**
   禁止换故事。拿出 0–1 那张 ASCII（如果有），在上面贴 1～3 个真名。公式每一项指回图上的一个东西。

6. **先问懂没懂（L0 必做；讲完落地句先停）**
   主动问这一课哪里对不上，允许自由提问。有图就问「哪一步对不上」；没有图就问「哪句没法用自己的话说」。
   对方沉默：给 **2～3 个**可选卡住点，且都必须是图上能指的。不要五个，不要空问「有问题吗？」。
   对方指出一块：只补那一块，同一张图、同一个故事，不要另开下一 phase。补完确认这块对上了。
   对方说没有 / 都对得上，或你判断这块已经对上：才进入课间确认。
   L1 可缩短成一句「旧图上哪个标签对不上」，不要每课从零闲聊。

7. **课间确认（对上了再出题）**
   三问都钉在这一课的例子和图上。有图就让对方指着图说。答不上来只补那一块。
   不要第四问基石 / LLM。不要对方说懂了还盘问个没完。不要一开口问「还有别的想学的吗」。
   提取题只写题干+due 进 ## 提取队列，答案不进卡。费曼对打在 feynman 课，不写标准答案进卡。

8. **保存 = 可读原文 + 章节补丁（一步，不是整卡重写）**
   用户说 **保存**、**写进库**、**记下来**、save、`/save-to-vault` 时：
   - 这就是同意写卡，并且必须带原文。不要再问「要不要同步进卡？」。
   - 读现有领域卡，`--body-file` 只写刚完成的那一 phase 的 frontmatter 变更 + 点名的 `##` 章节。未点名的章节由代码原样保留。
   - **原文是一篇给人读的讲解**：`##` 小标题、正文、例子、ASCII（若有）、课间确认。本课若画了 ASCII，必须原样写进这篇讲解。
   - 脏讲义（`用户：` / `助手：` / `孔明：` / `/learn`）代码会拒绝，不要洗完当合格。
   - 讲解页若还用自造正名，保存时改成原文词。以本课讲解为准，不要被旧页的「盯」拉回去。
   - `[pN]` 对应这篇讲解里第 N 段（空行分段），不是聊天第 N 轮。
   - `--note` 必须是 start 打印的真实路径，不要靠文件名猜。然后一次调用：

   ```bash
   gobs learn save --note <start打印的卡片路径> --body-file CARD.md --chat-file LECTURE.md --title "领域名"
   ```

   - `--chat-file` 里放讲解正文。过程课要把 ASCII 原样写进去，例如：

     没有它（排队）：The->cat->...->it；第8步包里最清楚的是 because，cat 已被挤过很多次。

     有它（attention）：it 同时问全班每一个字「你跟我有多相关」。

   - 升档仍须用户说「确认升到 L1」，且卡上 `artifact` 非空。无产物不得写 L1。
   - bloom 写入 create 会被夹成 analyze。

## 与 CLI 的关系

| 方式 | 何时用 |
| --- | --- |
| **普通 `gobs`** | 每天进库聊天（主入口） |
| **`/learn`** | 已在会话里，想立刻上课 |
| `gobs learn save` | 学习模式下「保存」：原文 + 领域卡补丁 |
| `gobs learn start NAME --no-launch` | 只建卡（本 skill 内部会调） |

## 禁止

- 要求用户关掉当前对话再执行一长串 CLI
- 一课做两个 phase；principles 一课新上超过 4 条；encode 课带另外 3 个组块
- 课堂上念整张卡、没说完「只要记住」就出题、空问「有问题吗」
- 有论文却另造正名（用「盯」代替 attention）；一课又讲故事又甩下一课零件（QKV、encoder、BLEU）
- 过程课无 ASCII 开讲；「没有它」只画箭头不画糊；硬给定界/判断课画装饰图
- 课间确认问基石/LLM；把整门课够用整段塞进 enough 以外的 phase
- 把问答 log / 提取答案 / 费曼标准答案写进领域卡
- L1 换故事、另起一张全新比喻
- 平行开第二课
- 把保存做成整卡重写，或拆成「先写卡」和「再归档原文」两步
- 把原文写成聊天 log（`/learn`、`用户：`、`助手：`、`孔明：`、`保存`）再洗一遍当合格
- 未确认或无 artifact 就升档
