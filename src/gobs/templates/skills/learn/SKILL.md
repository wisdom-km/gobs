# /learn — 当前会话内进入教练模式

主入口仍是普通 `gobs`。本 skill 只在用户已经进了会话、再切到 `/learn` 时用。
不要让用户退出去跑 `gobs learn start`。
未进入本 skill 时：改主题夹里的**讲解**页，不要改进度卡。

## 步骤

1. **领域名**
   - `/learn Transformer` 或 `/learn 英语` → 用该名称。
   - 只写了 `/learn` → 问一句：「学哪个领域？」等答复再继续。

2. **确保领域卡存在**（工作目录已是 vault）

   ```bash
   gobs learn start "领域名" --no-launch
   ```

   记下它打印的卡片相对路径。卡可能在主题文件夹里，不一定在 `22_study/00_learn/`。

3. **切换角色**
   - 读该领域卡和 `AGENTS.md` 学习协议。
   - 新课（卡几乎是空的）：若还没有定界，用对方的话记下场景 / 够用 / 停线。已经说清就不要再逼问，直接开讲。
   - 续学：从卡上 `open_door` 和缺口继续，不要从头来。
   - 一次一课：只干一件事，但这件事要讲细、讲满。四列表是课后档案，课堂上不要念表。

4. **怎么讲（L0 / 0–1：对零基础，不像考卷）**
   像默认 gobs 的「Attention Is All You Need 讲解」。观众是完全没学过术语的人。
   每一课按这个顺序，不要打乱：
   1. 一件具体麻烦（谁、在干什么、卡在哪）
   2. 一个生活里能看见的例子，从头演到尾
   3. 用**同一个**例子演：没有这一招会怎样
   4. 「这一课只要记住」2～3 句大白话，不含英文术语
   5. 课间确认：让对方用这个例子（和下面的图，如果有）自己说一遍

   **ASCII 图（能看见过程就必画，不适合就不画）**
   这一课如果是「怎么走 / 谁连谁 / 有它和没有它差在哪」，**必须**用 ASCII 画出过程，并在同一套图上画出「没有它会怎样」。图就是原理，写进讲解正文，保存进课次；不是装饰。
   只用 ASCII（代码块）。不要 mermaid、不要插画、不要生成图片。
   **不要硬画**：定界、够用/停线、纯判断、只给名字的贴纸课——没有过程可看，就别硬造一张图。拿不准就问自己：不画这张图，对方还能不能「看见」？看不见才画。

   术语、公式、论文原名：记住句说完再贴上去，先给中文人话。
   类比以能看懂为准，不在 L0 纠正「类比改了定义」。
   不要先甩英文名，不要先甩公式，不要按「对象 / 操作 / 约束 / 失败」讲课。

5. **L1 / 1–2（旧图贴名字）**
   禁止换故事、禁止另起一张全新比喻。拿出 0–1 那张 ASCII（如果有），在上面贴 1～3 个真名。公式每一项指回图上的一个东西。没有旧图就按第 4 步先画出过程，再贴名字。

6. **课间确认（讲完落地句再问）**
   问法绑在刚才的例子/图上。有图就让对方指着图说。不要一上来甩空的四问模板。
   答不上来只把这一课的画面再演一遍，不要另开新课。

7. **保存 = 可读原文 + 写进领域卡（一步）**
   用户说 **保存**、**写进库**、**记下来**、save、`/save-to-vault` 时：
   - 这就是同意写卡，并且必须带原文。不要再问「要不要同步进卡？」。
   - 读现有领域卡，只改刚完成的那一块，写出**完整**更新稿（保留 frontmatter 与未改章节）。
   - **原文是一篇给人读的讲解**，水准对齐默认 gobs 的「Attention Is All You Need 讲解」：`##` 小标题、正文、例子、课间确认。本课若画了 ASCII，必须原样写进这篇讲解，不当装饰。
   - 只收讲课内容。不要 `/learn`、`保存`、`学哪个领域`、`课开了`、`用户：`/`助手：` 轮次、tool 往返。
   - `[pN]` 对应这篇讲解里第 N 段（空行分段），不是聊天第 N 轮。
   - 卡片里不要贴聊天 log。然后一次调用：

   ```bash
   gobs learn save --note <start打印的卡片路径> --body-file CARD.md --chat-file LECTURE.md --title "领域名"
   ```

   - `--chat-file` 里放讲解正文。过程课要把 ASCII 原样写进去，例如：

     有它（盯）：it 同时问全班；cat #### 音量大；the . 几乎听不见。带走一包，不是冠军。

     没有它（排队）：The -> cat -> sat -> it。每传一步揉一次，到 it 已经糊。

   - 升档仍须用户说「确认升到 L1」。

## 与 CLI 的关系

| 方式 | 何时用 |
| --- | --- |
| **普通 `gobs`** | 每天进库聊天（主入口） |
| **`/learn`** | 已在会话里，想立刻上课 |
| `gobs learn save` | 学习模式下「保存」：原文 + 领域卡 |
| `gobs learn start NAME --no-launch` | 只建卡（本 skill 内部会调） |

## 禁止

- 要求用户关掉当前对话再执行一长串 CLI
- 课堂上念四列表、先甩英文术语/公式、没说完「只要记住」就考四问
- 过程课无 ASCII 开讲；硬给定界/判断课画装饰图；一课又讲故事又甩 QKV
- L1 换故事、另起一张全新比喻
- 平行开第二课
- 把保存拆成「先写卡」和「再归档原文」两步
- 把原文写成聊天 log（`/learn`、`用户：`、`助手：`、`保存`）
- 未确认就升档
