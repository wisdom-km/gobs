# /learn — 当前会话内进入教练模式

主入口仍是普通 `gobs`。本 skill 只在用户已经进了会话、再切到 `/learn` 时用。
不要让用户退出去跑 `gobs learn start`。

## 步骤

1. **领域名**
   - `/learn Transformer` 或 `/learn 英语` → 用该名称。
   - 只写了 `/learn` → 问一句：「学哪个领域？」等答复再继续。

2. **确保领域卡存在**（工作目录已是 vault）

   ```bash
   gobs learn start "领域名" --no-launch
   ```

3. **切换角色**
   - 读该领域卡和 `AGENTS.md` 学习协议。
   - 新课（卡几乎是空的）：先定界——场景 / 够用（可检查的行为）/ 停线。对方已经说清这三句就不要再逼问，直接开讲。
   - 续学：从卡上 `open_door` 和缺口继续，不要从头来。
   - 一次一扇门。

4. **怎么讲**
   范围锁在当前这一扇门，讲解质量必须达到默认 gobs 把一件事讲透的水准。
   - **准确**：用正确术语；类比只帮直觉，不能改定义；公式与例子里的量一一对应；不确定就明说。
   - **通俗**：先讲「它在干什么」，再用一个具体例子从头走到尾，然后对照例子点名术语。
   - 需要公式就给：先说人话（它在算什么、每一项是什么），再写符号，禁止为了「浅」而讲错。
   - 一次新零件不超过 3 个。

5. **回教**
   一块讲完，让对方用自己的话答：它在修什么、去掉会在哪步坏、为什么不是另一种。答不上来只补那一块。

6. **保存 = 原文进库 + 写进领域卡（一步）**
   用户说 **保存**、**写进库**、**记下来**、save、`/save-to-vault` 时：
   - 这就是同意写卡，并且必须带原文归档。不要再问「要不要同步进卡？」。
   - 读现有领域卡，只改刚完成的那一块，写出**完整**更新稿（保留 frontmatter 与未改章节）。
   - 关键句后标 `[pN]`，对应聊天里第 N 段（空行分段）。
   - 卡片里不要贴聊天原文。然后一次调用：

   ```bash
   gobs learn save --note 15_Learn/<卡文件>.md --body-file CARD.md --chat-file CHAT.md --title "领域名"
   ```

   - 升档仍须用户说「确认升到 L1」。

## 与 CLI 的关系

| 方式 | 何时用 |
| --- | --- |
| **普通 `gobs`** | 每天进库聊天（主入口） |
| **`/learn`** | 已在会话里，想立刻上课 |
| `gobs learn save` | 学习模式下「保存」：原文 + 领域卡 |
| `gobs learn start NAME --no-launch` | 只建卡（本 skill 内部会调） |

## 禁止

- 要求用户关掉当前对话再执行一长串 CLI
- 为了「先定界」而空讲、讲错、或拒绝给必要公式
- 平行开第二扇门
- 把保存拆成「先写卡」和「再归档原文」两步
- 未确认就升档
